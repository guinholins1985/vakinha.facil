# PREMIX - Plataforma de Jogos e Painel de Administração

PREMIX é uma plataforma de administração de nível empresarial, projetada para oferecer controle total sobre operações de cassino e apostas, combinada com um poderoso conjunto de ferramentas para marketing e arrecadação de fundos.

## ✨ Sobre o Projeto

O painel PREMIX foi desenvolvido para ser uma solução "tudo-em-um" para operadores de plataformas online. Ele oferece uma interface intuitiva e funcionalidades robustas para gerenciar todos os aspectos do negócio, desde a configuração de jogos e pagamentos até a criação de campanhas de engajamento para os usuários.

A plataforma também conta com uma página inicial moderna e profissional para atrair e engajar novos jogadores.

## 🚀 Tecnologias

- **React:** Biblioteca JavaScript para construir interfaces de usuário.
- **TypeScript:** Superset de JavaScript que adiciona tipagem estática.
- **Tailwind CSS:** Framework CSS utility-first para estilização rápida e responsiva.

## 🎯 Funcionalidades

- **Página Inicial Completa:** Uma landing page profissional para apresentar a plataforma aos usuários.
- **Dashboard de Gestão:** Uma visão geral completa com as métricas mais importantes da plataforma.
- **Gestão de Jogos:** Controle total sobre o catálogo de jogos, provedores e categorias.
- **Arrecadação & Marketing:**
  - **Vaquinhas:** Crie e gerencie campanhas de crowdfunding.
  - **Rifas:** Organize e acompanhe sorteios.
  - **Cupons de Desconto:** Crie e monitore cupons promocionais.
- **Gestão de Usuários e Financeiro:** Administração de usuários, carteiras, depósitos e saques.
- **Configurações Avançadas:** Personalização completa da plataforma, incluindo aparência (logos, cores, CSS/JS customizado), banners, e-mails (SMTP) e integrações de API.
- **Múltiplos Gateways de Pagamento:** Interface para gerenciar e configurar diversos gateways de pagamento.
