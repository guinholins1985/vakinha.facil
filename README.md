# PREMIX - Plataforma de Arrecadação e Entretenimento

PREMIX é uma plataforma moderna que combina arrecadação de fundos através de vaquinhas online, sorteios com rifas, e entretenimento com jogos de slot. Este repositório contém o código-fonte do front-end da aplicação, construído com React e Tailwind CSS.

## ✨ Sobre o Projeto

O PREMIX foi projetado para ser uma solução completa e segura para campanhas de arrecadação e eventos online. A plataforma oferece uma interface intuitiva tanto para os criadores de campanhas quanto para os participantes, garantindo transparência e facilidade de uso.

## 🚀 Tecnologias

Este projeto foi construído com as seguintes tecnologias:

- **React:** Biblioteca JavaScript para construir interfaces de usuário.
- **TypeScript:** Superset de JavaScript que adiciona tipagem estática.
- **Tailwind CSS:** Framework CSS utility-first para estilização rápida e responsiva.
- **Vite:** Ferramenta de build para desenvolvimento front-end moderno.
- **Gemini API:** Para futuras integrações de IA.

## 🎯 Funcionalidades

- **Dashboard de Gestão:** Uma visão geral completa das atividades da plataforma.
- **Criação de Campanhas:** Ferramentas para criar vaquinhas, rifas e outros eventos.
- **Gestão de Usuários:** Administração de usuários e permissões.
- **Configurações da Plataforma:** Personalização de banners, e-mails e integrações.
- **Integração com Gateways de Pagamento:** Para transações seguras e automatizadas.

## 🏃 Como Executar

Para executar este projeto em um ambiente de desenvolvimento:

1. Clone o repositório.
2. Instale as dependências com `npm install`.
3. Inicie o servidor de desenvolvimento com `npm run dev`.
4. Abra `http://localhost:5173` no seu navegador.
